The technology stack. The front end is React 18, built with Vite, as a single-page app. The back end is Python 3.12 with FastAPI, which serves a REST API and holds all the business rules and role-based access. Data lives in SQLite: one file, upgraded automatically at start-up. The AI service is a separate FastAPI app running free local models with PyTorch and ONNX on the CPU. We integrate PVGIS, the European Commission’s solar calculator, for generation estimates, Razorpay for online payments, Google sign-in and email. Quality comes from 63 automated tests with pytest, and the code is versioned with Git on GitHub.
