Here is a real quote the system produces for a 3 kilowatt on-grid package. The kit is 1,44,000 rupees and installation 15,000. GST is applied the current way: 5 percent on solar equipment since the September 2025 cut, and 18 percent on installation, so 9,900 rupees. Total 1,68,900.
