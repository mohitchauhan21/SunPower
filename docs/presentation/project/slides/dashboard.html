The director gets one view of the business: invoiced versus collected, installations done and still waiting, profit per installation with loss-making jobs flagged in orange, subsidy files in progress, open repairs and any stock shortages. It can be switched between day, week, month and year, and there is a printable report that can be emailed. The figures on this slide are an illustration; in the demo the same panels read live data.
